💬 Say It Nicely

Type a rough message, get a polished one in your own voice. The AI is an open-weight model (Gemma 2 2B by default) running inside your browser via WebLLM: no server, no API key, no account, and your private messages never leave your device.

Use it
Open the live link in desktop Chrome or Edge (needs WebGPU).
Click Load the AI (one-time download, then cached and works offline).
Pick who it's for, the tone and language, type a rough message, click Say it nicely.
Tech

WebLLM (MLC) + Gemma 2 2B / Qwen 2.5 1.5B / Llama 3.2 1B on WebGPU. Plain HTML, CSS and JavaScript in a single file.
